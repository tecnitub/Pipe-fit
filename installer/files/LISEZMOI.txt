PIPE-FIT CRM - Mode d'emploi rapide
====================================

INSTALLATION
  Double-cliquez sur PipeFitCRM-Setup.exe sur le PC qui servira de serveur
  (un PC allumé en permanence, Windows 10 ou 11, 64 bits).
  Le navigateur s'ouvre ensuite : créez le compte administrateur.

UTILISATION
  - Sur le serveur : icône « Pipe-Fit CRM » sur le bureau (http://localhost:3000).
  - Sur les autres postes : ouvrir http://NOM-DU-SERVEUR:3000 dans le navigateur
    (Chrome, Edge ou Firefox). Aucune installation sur les postes.
  - Créez les comptes de vos collègues dans Paramètres > Comptes utilisateurs.

LE SERVEUR
  Il démarre automatiquement avec Windows (tâche planifiée « PipeFitCRM »),
  même si personne n'ouvre de session. Le pare-feu Windows est ouvert sur le
  port 3000 pour les réseaux « Domaine » et « Privé ».
  Si les collègues n'arrivent pas à se connecter : vérifier que le réseau du
  serveur est en « Privé » (Paramètres Windows > Réseau).

APPLICATION DOE
  Installée avec le CRM (tâche planifiée « PipeFitDOE ») : http://NOM-DU-SERVEUR:3100
  Journal : C:\ProgramData\PipeFitCRM\logs\doe.log

APPLICATION ÉTUDES (notes de calcul du bureau d'études)
  Installée avec le CRM (tâche planifiée « PipeFitEtudes ») : http://NOM-DU-SERVEUR:3200
  Journal : C:\ProgramData\PipeFitCRM\logs\etudes.log

DONNÉES ET SAUVEGARDE
  Toutes les données sont dans : C:\ProgramData\PipeFitCRM\data
  Sauvegarde automatique chaque soir : Paramètres > Pièces jointes et sauvegardes
  sur le réseau (choisir un dossier sur un autre disque ou un NAS).
  Journal du serveur : C:\ProgramData\PipeFitCRM\logs\serveur.log

CONFIGURATION DU SERVEUR (dossiers réseau, partage, HTTPS, compte de service)
  Script deploy\windows\configurer-serveur.ps1 du pack de déploiement.
  Mode d'emploi complet : docs\guide-installation.html du pack.

MISE À JOUR
  Lancez simplement le nouveau PipeFitCRM-Setup.exe : les données sont conservées.

HTTPS (connexion chiffrée)
  Indispensable pour l'appli des compagnons et pour tout accès depuis l'extérieur.
  Déposez le certificat de l'entreprise (émis par une autorité reconnue) dans :
      C:\ProgramData\PipeFitCRM\data\tls
  soit cert.pem + key.pem, soit certificat.pfx ; dans ce cas créez le fichier
  C:\ProgramData\PipeFitCRM\config.cmd contenant :
      set "TLS_PASSPHRASE=mot de passe du PFX"
  puis redémarrez le PC. Adresse pour les collègues : https://NOM-DU-SERVEUR:3000
  (les anciennes adresses http:// sont renvoyées automatiquement vers https://).
  L'état du certificat est affiché dans Paramètres > Sécurité.

CHANGER DE PORT
  Créer le fichier C:\ProgramData\PipeFitCRM\config.cmd contenant :
      set "PORT=8080"
  puis redémarrer le PC (et adapter la règle de pare-feu « Pipe-Fit CRM »).

DÉSINSTALLATION
  Paramètres Windows > Applications > Pipe-Fit CRM > Désinstaller.
  Les données ne sont supprimées que si vous le confirmez.
